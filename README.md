Desenvolvimento Front End: HTML, CSS, JavaScript, Vue.js e Git
Este repositório contém o aprendizado e os projetos desenvolvidos durante o curso "Desenvolvimento Front End: HTML, CSS, JavaScript, Vue.js e Git". 
O objetivo do curso foi proporcionar uma base sólida para o desenvolvimento de sites e aplicações web modernas.

O que você aprenderá
Desenvolvimento de Sites e Aplicações Web Modernas
Trabalhar com Protótipos de Web Design feitos com Figma e Invision, e seguir as especificações do projeto
Construir Sites Responsivos para celulares, tablets e desktops usando CSS Media Queries
HTML & CSS do zero ao avançado
JavaScript do zero ao avançado
Vue.js do zero ao avançado para construção de aplicações web modernas
Vue 3 com Options API e Composition API
Gerenciamento de estado com Pinia
Resolução de Tarefas Comuns em JavaScript:
Countdowns
Elementos dinâmicos
Filtros e muito mais
Trabalhar com Requisições HTTP e JSON para consumo de dados de APIs
Publicação de Sites em serviços gratuitos e pagos de hosting
Gestão de DNS e aquisição de domínios como .com, .br, etc.
SEO básico, utilizando elementos semânticos do HTML5 e otimização do DOM
Gerenciamento de Repositórios Git, para colaborar com outros desenvolvedores
Requisitos
Conhecimentos básicos de informática
Acesso à internet
Para quem é este curso?
Estudantes buscando iniciar carreira no desenvolvimento web
Empreendedores que desejam desenvolver e vender sites customizados para empresas
Pessoas com vontade de dar os primeiros passos em programação e escrita de código
Qualquer pessoa que tenha vontade de aprender novas habilidades e tecnologias
Projetos desenvolvidos
Durante o curso, foram criados diversos projetos práticos utilizando as tecnologias mencionadas. Estes projetos visam aplicar os conhecimentos adquiridos e mostrar como os conceitos se integram para criar sites e aplicações funcionais.

Tecnologias
HTML5
CSS3 (com ênfase em responsividade e Media Queries)
JavaScript (vanilla, sem frameworks)
Vue.js 3 (com Pinia para gerenciamento de estado)
Git e GitHub (controle de versão e colaboração)
Links úteis
Figma - Ferramenta de design de interfaces
Invision - Protótipos e design colaborativo
GitHub - Repositórios de código
